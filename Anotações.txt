pergunta da aula -> Qual a diferença entre classe abstrata e interface.
Resumindo:
Classe abstrata → serve como uma base para outras classes. Pode ter atributos, métodos concretos e métodos abstratos.

Interface → define um contrato: diz quais métodos uma classe deve implementar, sem necessariamente definir como.

Exemplo simples:

Classe abstrata: Animal → pode ter nome e um método comer().

Interface: Voador → define que deve existir voar().

👉 Classe abstrata = “é um”
👉 Interface = “sabe fazer”
